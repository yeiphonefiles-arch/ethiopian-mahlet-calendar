EOTC Mahlet PDF Encryption Tool

Encrypt raw Mahlet PDF files using AES-GCM 256-bit encryption with PBKDF2 key derivation (100,000 iterations). Output files can be deployed directly to the site.

Save this file into: pdfs/<month-folder>/ on the site (e.g. pdfs/meskerem/01-mahlet.pdf.enc).
