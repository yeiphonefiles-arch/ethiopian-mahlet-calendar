EOTC Daily Service PDF Encryption Tool

Encrypt raw service PDFs (Mahlet, Gitsawe, Mezmur, Qedassie) using AES-GCM 256-bit encryption with PBKDF2 key derivation (100,000 iterations). Output files can be deployed directly to the site.

These dates shift every Ethiopian year (except Genna/Timkat, which are fixed but still get their own special service files), so they live in one shared folder instead of a specific day-of-month folder.
